# ReproBridge project page

Source of the project website for **ReproBridge: Building Reproducibility into ML Research Artifacts**
(Yubo Wang, Rui Meng, Jaehyun Nam, Tomas Pfister, Jinsung Yoon; University of Waterloo, Google).

Live: https://wyyyb.github.io/reprobridge_website/

It is a static site with no framework, bundler or runtime dependencies. GitHub Pages serves the repository root.

## Layout

| Path | Content |
| --- | --- |
| `index.html` | Generated by `build.py`; do not edit by hand |
| `src/head.html`, `src/tail.html` | Document head (meta, fonts, theme bootstrap) and closing scripts |
| `src/partials/NN-<id>.html` | One file per page section, concatenated in filename order |
| `assets/css/base.css` | Design system: tokens (light and dark), layout, shared components |
| `assets/css/<id>.css`, `assets/js/<id>.js` | Section styles and behaviour, linked automatically when present |
| `assets/js/site.js`, `assets/js/charts.js` | Shell (theme, navigation, reveal, lightbox, copy) and SVG chart helpers |
| `assets/js/data.js` | `window.RB_DATA`, every number the charts use; generated from the paper |
| `assets/img/` | Paper figures (WebP), favicon, social card |
| `tools/build_data.py`, `tools/paper_meta.json` | Data generator and the 36-paper coverage taxonomy |

## Build

```bash
python3 build.py                                      # regenerate index.html
python3 build.py --only results --out .preview-x.html # preview selected sections (gitignored)
python3 -m http.server 8000                           # then open http://localhost:8000/
```

Asset URLs carry content hashes, so a rebuild is enough to bust caches.

## Numbers

All chart data comes from the paper's LaTeX sources:

```bash
python3 tools/build_data.py --paper ../reprobridge_arxiv
python3 build.py
```

The generator parses the paper's `tables/*.tex` and asserts that every number taken from running text still appears
in the source (76 checks), plus consistency checks. For example, the per-paper inventory must reproduce the paper's
task totals, paper-macro rates and figure legend counts. If the paper changes a number, the build fails instead of
publishing a stale value.

## Before launch

- Delete the `<meta name="robots" content="noindex, nofollow">` line in `src/head.html` so search engines can index the page.
- Replace the "Soon" buttons in `src/partials/01-hero.html`, `00-nav.html` and `10-release.html` with links to
  the paper, arXiv, code and ReproBridge-Bench. Add the arXiv identifier to the BibTeX entry.
- Rebuild with `python3 build.py`, commit, and push; Pages redeploys automatically.
