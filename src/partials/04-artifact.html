Example Effective Model Pruning

The released loader silently labels all 10,000 TinyImageNet validation images as one class. During construction, ReproBridge adds a script organizing images by their true labels and a launcher check requiring prepared data. In paired Gemini 3.8 Flash runs, ResNet-18 validation loss changes from 8.898 on raw code to 2.288 with the refined artifact, close to the paper’s 2.303.

What is inside an artifact

The normalized refined artifact has seven top-level entries. Its guide connects instructions to their rationale through an ambiguity table, and the change record distinguishes execution fixes, correctness fixes, and convenience changes while retaining pitfalls and open choices.

Inside a guide: SCIQL

The paper’s condensed guide for SCIQL keeps all twelve section headings in their original order. It links a renamed-package issue to a compatibility launcher and a minimum-episode check, preserving both an executable route and the reason for it.

reproduction_guideline.md 12 sections

# Reproducing Table 1 of SCIQL

## What this is

- Table 1: style alignment for CBC, SCBC, and SCIQL.

- Released Circle2D and HalfCheetah datasets; code commit `5389c6e`.

## Hardware

- One GPU per repetition; this guide used NVIDIA H100 80 GB.

## Software

- Python 3.10; JAX 0.5.2; NumPy 2.2.3; PyTorch 2.5.1+cpu.

- JAX runs on the GPU; PyTorch is used for logging.

## Environment setup

```bash

bash setup/01_environment.sh

source .venv/bin/activate

DATA_ROOT=/data bash setup/02_data.sh

```

## Artifacts

- `datasets.zip`: SHA-256 checked; 1,000 episodes per Circle2D dataset.

- No released checkpoints; each experiment trains from scratch.

## Experiments

- G15: SCIQL × circle2d-inplace-v0; one seed, all six style criteria.

```bash

DATA_ROOT=/data OUTPUT_ROOT=/outputs bash experiments/run_G15.sh 0

```

## Repetitions and variance

- Run index = seed; the paper reports a mean over five seeds.

- Use distinct seeds and retain every run, including low-scoring runs.

## Outputs and metrics

- `$OUTPUT_ROOT/G15/run0/metrics.json`, key: `alignment_x100`.

- Unweighted mean over labels, then criteria, multiplied by 100.

## Paths

- `DATA_ROOT`: datasets. `OUTPUT_ROOT`: new measurements and logs.

- `src/datasets/traj2d` links into `$DATA_ROOT/episodes/traj2d`.

## Ambiguities and unspecified details

- A1: use unweighted aggregation; checked against Appendix Table 3.

- A3: released episodes refer to the old package name `style_bench`.

- Adopt aliases to `sciql.core.data` in `src/tools/sciql_launch.py`;

retain the released episode classes.

## Known pitfalls

- Symptom: exit 0 and a plausible CSV, despite loading no episodes.

- Cause: import errors are caught and skipped by the loader.

- Fix: use the compatibility launcher and keep `--min-episodes 1000`.

- Keep smoke outputs separate from full runs (`run<i>.smoke/`).

## What is not covered

- HumEnv: the released datasets and integration code are missing.

- Experiments outside Table 1.

How ReproBridge builds it

Humans define the workflow, delivery standards, and protocols; agents perform all construction, review, and packaging. Specify fixes the intended experiment before execution; Execute establishes a working procedure and records measurements, repairs, and failures; Preserve packages that procedure and its rationale for reuse.

Persistent evidence

Each measurement links to an actual output file; blocked tasks retain an explicit failure reason; diagnostic runs stay separate from scored repetitions.

Paper over code

When paper and code conflict, agents follow the paper’s setup and flag the discrepancy.

Clean-shell delivery

Supplied entry points are tested from a clean shell, including an inexpensive real repetition; human reference information is withheld throughout construction.
