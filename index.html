Building Reproducibility into
ML Research Artifacts

Paper Soon arXiv Soon Code Soon Dataset Soon

Reproducing an ML experiment often requires recovering details that its paper and released code leave implicit, and even a successful attempt can leave those decisions buried in conversations or shell histories. ReproBridge preserves them as a refined reproducible artifact: refined code, environment setup, experiment launchers, and a reproduction guide. Across four coding agents on 1,029 tasks, refined artifacts raise mean reproduction success from 76.4% to 92.6% and reduce downstream API spending by 19.7% on average.
